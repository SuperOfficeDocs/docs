Before users can use SuperOffice AI capabilities, an administrator must enable AI functions for the organization. Some functions, such as AI agents, require additional setup.

## Enable AI functions

1. Go to **Settings and maintenance** > **Preferences** > **Global preferences** > **AI**.
1. Set **Enable AI functions in SuperOffice** to **Yes**.
1. Select **Save**.

![Enable AI functions in SuperOffice set to Yes, highlighted in the AI global preferences -screenshot][img1]

## Enable text analysis {#enable-text-analysis}

1. Open **Settings and maintenance**.
1. Select **AI services** from the Navigator.
1. Under **Text analysis**, select the checkboxes for the features you want to use: **Language detection**, **Translate message**, and **Sentiment analysis**.

    ![Text analysis checkboxes in AI services -screenshot][img2]

## AI global preferences {#global}

These preferences apply to the whole system. To change them, go to **Settings and maintenance** > **Preferences** > **Global preferences**, and find the **AI** section.

| Preference | What it does |
|---|---|
| Enable AI functions in SuperOffice | Shows the AI buttons and panels in SuperOffice. When set to **No**, they are hidden. The default is **Yes**. |
| Allow Leadfeeder usage | Lets agents use Leadfeeder to verify and enrich companies. |
| Allow contact enrichment | Lets the Data Quality Agent add and update contacts when it enriches companies. When set to **No**, users cannot turn on the agent's **Enrich contacts** option. This also applies to contact enrichment outside the agents. The default is **No**. |
| Maximum AI credits usage | The total number of AI credits that can be used. Agents stop creating tasks when usage reaches the limit. |
| Enable Data Quality Agent, Enable Duplicate Agent, Enable Lead Agent, Enable Sales Assistant Agent | Turns each agent on or off for all users. When set to **No**, the agent stops creating tasks. |
| Credit limit Data Quality Agents, Credit limit Duplicate Agents, Credit limit Lead Agents, Credit limit Sales Assistant Agents, Credit limit Leadfeeder | The credit limit for each agent and for Leadfeeder. An agent stops creating tasks when it reaches its limit. |

<Tip>
The agent switches, credit limits, and extra credit packages are easier to manage on the [Agent Limits][5] tab, which also shows the credits used this month.
</Tip>

The **SuperOffice Workspace Assist** section has one preference:

| Preference | What it does |
|---|---|
| Allow Workspace Assistant access to the web | Lets [Workspace Assist][6] use information from the web in its answers. |

## AI preferences per user {#preferences-tab}

These preferences can be set for the whole database, for a group, or for one user. Users can also have their own setting for each of them. For how levels work, see [Levels for preference settings][7].

1. Go to **Settings and maintenance** > **Preferences** > **Preferences**.
1. Select **AI** in the list of preference groups.
1. Select a preference, then add or change its settings under **Active settings**.

| Preference | What it does |
|---|---|
| Automatically generate reply to a message | Generates a [Reply Assist][8] suggestion when a user clicks **Reply** or **Reply all** on a request. |
| Enable AI agents | Lets users set up their own [AI agents][2]. When set to **No**, the **Agents** icon is hidden in the Navigator. The default is **Yes**. |
| MCP access control | Controls what [MCP Connect][3] clients can do in SuperOffice: read and update (**All**, the default), only read, or nothing. |
| Show AI Reply Assist suggestion | Shows the [Reply Assist][8] suggestion when a user replies to a request. |
