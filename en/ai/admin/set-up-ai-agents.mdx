<Note>
SuperOffice's AI agents are coming soon. This page describes set-up steps for a feature that is not generally available yet.
</Note>

SuperOffice's AI agents work in the background and propose results for a person to approve. Every agent opens, activates, and is managed the same way. This page covers those shared steps once, then a section per agent for its own set-up.

See [Open the Agents area][open-agents-area] for the sign-in steps. The **Agents** icon only appears once AI functions are enabled, below.

## Enable AI functions

The **Agents** icon appears in the Navigator only when **Enable AI functions in SuperOffice** is set to **Yes** in CRM global preferences.

1. Go to **Settings and maintenance** > **Preferences** > **Global preferences** > **AI**.
1. Set **Enable AI functions in SuperOffice** to **Yes**.

![Enable AI functions in SuperOffice must be set to Yes -screenshot][img2]

## Find and activate an agent

The **Agents** page shows a starter set of agent cards. To see every agent in your subscription:

1. Select **Browse agents** in the top-right of the **Agents** page.
1. Use the search box or the category filters to find the agent you want.
1. Select **Activate** to open that agent's set-up wizard and create your first **instance**: one configured, running copy of the agent.

![The Agents page's default cards and the Browse agents drawer -screenshot][img3]

<Note>
**Browse agents** only shows agents included in your subscription tier. If an agent you expect is not listed, contact your SuperOffice administrator or partner.
</Note>

Once an agent has an instance, its card shows an **N active** link instead of **Activate**. Select it to see the agent's instances, grouped Active and Inactive, and open any of them. Agents that allow more than one instance also show a **+ New instance** button, so you can add another at any time.

![The instances popover on an agent's card -screenshot][img4]

<Note>
See [Agent instances][agent-instances] for how many instances each agent allows.
</Note>

![Browse agents keeps a + New instance option for agents that allow more than one -screenshot][img5]

## Manage an instance

Only the instance's owner (its creator) can edit its settings, activate or deactivate it, or delete it.

* **Edit settings**: select the edit (pencil) button in the instance header to open the same set-up dialog. Changes apply from the next run.

    ![The edit dialog as an approver sees it (read-only), and as the owner sees it (editable) -screenshot][img6]

* **Notify**: every user with access to the instance has their own **Notify** bell toggle. Muting only affects that person. The instance keeps running for everyone else.

    ![The per-user Notify toggle -screenshot][img7]

* **Activate or deactivate**: use the **Active** toggle in the instance's three-dots menu.

    <Warning>
    Deactivating an instance discards any tasks awaiting review. This cannot be undone.
    </Warning>

    ![Deactivating from the three-dots menu, with the pending-approvals warning -screenshot][img8]

* **Delete**: available once an instance is deactivated, from the same three-dots menu.

    <Danger>
    Deleting an instance is permanent and removes all its data.
    </Danger>

    ![Deleting an instance from the three-dots menu and the confirmation -screenshot][img9]

* **About this agent**: select **About** from the three-dots menu for a read-only summary, including display name, agent type, owner, activation date, schedule, and approvers.

    ![The About this agent summary -screenshot][img10]

## Set up Lead Agent {#lead-agent}

Lead Agent's set-up wizard has 4 required steps:

| # | Step | What it covers |
|---|---|---|
| 1 | General settings | Name, region and language, schedule, daily volume, add contacts |
| 2 | Ideal customer | Instructions that define a good lead |
| 3 | Sources | News sources to scan, plus enrichment sources |
| 4 | Approvers | Who reviews and approves the leads |

### 1. General settings

* **Name**: identifies the instance. It must be unique and cannot be changed after activation.
* **Description**: pre-filled with a suggested summary. Edit it if you want something different.
* **Country**: defaults to your organization's home country, and sets both the registries the agent searches and the country it scans by default.
* **Reporting language**: the language the agent writes its reports and chat replies in.
* **Schedule**: the agent runs **Daily**, once a day at a system-assigned time.
* **Max tasks per day**: caps how many approval tasks the agent creates each day (1, 2, 5, 10, 15, 20, 25, or 30; default 10), so the review volume stays manageable.
* **Add contacts**: when on, the agent also finds contact persons for each lead, with email and phone details. When off, it works at company level only.

<Note>
**Your ideal customer profile's location wins over Country.** The **Country** you pick is only a default. For example, selecting Germany but naming France in your profile makes the agent search French registries and scan French leads.
</Note>

![The Lead Agent setup wizard, General settings -screenshot][img11]

### 2. Ideal customer

This defines what counts as a good lead and how the agent should behave.

**Instructions**: in plain language, describe the customers you want and how the agent should work. Be specific, for example: *Focus on companies showing growth signals, such as recent funding, new offices, or hiring.*

<Tip>
Cover what matters, such as industry, size, and region, plus disqualifiers such as "not public sector." Refine it any time; changes apply to future runs.
</Tip>

![Defining your ideal customer -screenshot][img12]

### 3. Sources

* **News sources**: public sources the agent scans for buying signals. Add each with a label and web address.
* **Enrichment sources**: used to verify and enrich each lead.
  * **Built-in sources**: business registries selected automatically for your country, for example Brønnøysundregistret for Norway or Northdata for Germany.
  * **Leadfeeder**: a B2B company-data service that enriches and prioritizes discovered leads. On by default for new instances; turn it off to rely on web scraping alone.

![The Sources step, with enrichment sources including Leadfeeder -screenshot][img13]

### 4. Approvers

Choose who reviews and approves the leads this agent finds. Approving a lead makes that person its owner. For Lead Agent, the approver can be someone other than the instance owner.

How leads are **shared** between approvers depends on how many you add:

* **One approver**: every lead goes to that person, and the sharing setting is disabled.
* **Two or more approvers, or a group**:
  * **First come, first served**: the first person to act owns the lead, and it clears from the others' queue.
  * **Round-robin**: each new lead goes to the next approver in turn.

<Warning>
The **First come, first served** / **Round-robin** choice is set when you create the instance and cannot be changed afterwards. You can still add or remove approvers.
</Warning>

![Choosing approvers -screenshot][img14]

Select **Save** on the last step to activate the instance.
