This provider name is implemented by the class `SuperOffice.CRM.ArchiveLists.Archive.FormSelectionDynamicProviderSingleCriteriaGroup` inside NetServer's SODatabase assembly.

Form selection archive using the selectionId as criterionmapping.
There is no shadow variant, since a form has no person to shadow onto.

The criteria the user gets to pick from are the columns of `FormFormExtender` - the same
ones the Forms pane shows - so a column that should be usable as a criterion needs a restriction type
on its `ArchiveColumnInfo` in `FormExtenderBase` and nothing more here.
