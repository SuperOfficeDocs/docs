## "FlowStaticSelectionV2"

This provider name is implemented by the class SuperOffice.CRM.ArchiveLists.Archive.FlowSelectionStaticProviderV2 inside NetServer's SODatabase assembly.

Static archive provider for a Selection of Flows archive.

No shadow counterpart and no combined provider: a flow has no person to shadow onto, and combined selections
are not offered for the marketing entities (the combined slot in
SelectionTypeStore stays empty, as it does for mailings and forms).
