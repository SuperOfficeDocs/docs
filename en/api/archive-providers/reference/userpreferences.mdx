## "UserPreferences"

This provider name is implemented by the class SuperOffice.CRM.ArchiveLists.UserPreferencesProvider inside NetServer's SODatabase assembly.

User (and system) preference settings, at all levels

The SoPreference class will return the <b>current</b> setting for a preference for the current principal.
This archive provider is for administrative purposes, and returns <b>all</b> settings for the preference(s) selected.
<br />
Preferences have multiple sources: the userpreference table ([UserPreferenceTableProvider](./userpreferencetable), and various
Service settings that are mapped into preferences, retrieved by [MappedPreferenceProvider](./mappedpreferences).
