## "FlowDynamicSelectionSingleCriteriaGroup"

This provider name is implemented by the class <see cref="T:SuperOffice.CRM.ArchiveLists.Archive.FlowSelectionDynamicProviderSingleCriteriaGroup">SuperOffice.CRM.ArchiveLists.Archive.FlowSelectionDynamicProviderSingleCriteriaGroup</see> inside NetServer's SODatabase assembly.

Flow selection archive using the selectionId as criterionmapping.
There is no shadow variant, since a flow has no person to shadow onto.

The criteria the user gets to pick from are the columns of <see cref="T:SuperOffice.CRM.ArchiveLists.EmailFlowEmailFlowExtender" /> - the same
ones the Flows pane shows - so a column that should be usable as a criterion needs a restriction type on its
<see cref="T:SuperOffice.CRM.ArchiveLists.ArchiveColumnInfo" /> in <see cref="T:SuperOffice.CRM.ArchiveLists.EmailFlowExtenderBase" /> / <see cref="T:SuperOffice.CRM.ArchiveLists.WorkflowExtenderBase" /> and nothing more here.
