The WebApi Client offers an alternative to the existing SuperOffice NetServer WCF proxies. **[SuperOffice.WebApi][1109]** has the exact same Agent-style services as [SuperOffice.NetServer.Services][1108] while adopting modern practices, such as asynchronous methods.

This library is a **.NET Standard 2.0 library** that works with both .NET Framework (4.6.1 and higher) and .NET Core (2.0 and higher) applications.

[1108]: https://www.nuget.org/packages/SuperOffice.NetServer.Services
[1109]: https://www.nuget.org/packages/SuperOffice.WebApi
