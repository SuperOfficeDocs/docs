MDO provider that returns webhook entity types found in the webhook table.
Scans the Events property across all webhooks, extracts entity names (the part before the dot),
and maps them to predefined display names. Custom objects are resolved by their friendly name
and listed after predefined entities. Entities not in either list are grouped as "Custom".

Implemented by the `SuperOffice.CRM.Lists.WebhookEntityListProvider` class.
The name of the MDO list is 'webhookentitylist'.

## Sample Request

```http!
GET /api/v1/MDOList/webhookentitylist
Authorization: Basic dGplMDpUamUw
Accept: application/json; charset=utf-8

```

## Sample Code
```cs
var listProvider = ClassFactory.CreateRequired<SuperOffice.CRM.Lists.ISoListProviderFactory>().Create("webhookentitylist", forceFlatList: true);
foreach (var item in listProvider.RootItems) {
    Console.WriteLine("{0} {1} {2} {3}", 
         item.Id, ResourceManager.ParseInlineResources(item.Name), item.StyleHint, item.ExtraInfo);
}
```
