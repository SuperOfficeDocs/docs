## "customobjecticon" MDO List
Custom object icons uploaded as SVG files, whether or not a custom object uses them.
ExtraInfo holds the number of custom objects using each icon.



Implemented by the <see cref="T:SuperOffice.CRM.Lists.CustomObjectIconProvider">CustomObjectIconProvider</see> class.
The name of the MDO list is 'customobjecticon'.
