## ticket\_attachment Table (256)

This table connects an attachment to a message. It references the entry in the attachment table, and the message.

## Fields

| Name | Description | Type | Nullable |
|------|-------------|------|:----:|
|id|The primary key (auto-incremented)|PK|No|
|attachment\_id|The attachment.id this reference is connected to.|FK [attachment](./attachment.mdx)|Yes|
|message\_id|The message.id this reference is connected to.|FK [ej_message](./ej-message.mdx)|No|
|content\_id|The content_id of this attachment, used for inline images|String(255)|Yes|
|inline\_image|True if this attachment is inlined in the html_body.|Bool|No|
