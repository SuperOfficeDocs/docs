## element\_profile Table (328)

The new (4.0) profile table. Contains profile for a single Html-element. Connected through element_profile_link

## Fields

| Name | Description | Type | Nullable |
|------|-------------|------|:----:|
|id|The primary key (auto-incremented)|PK|No|
|name|This is the name used by common profiles|String(255)|Yes|
|static\_element|An enum for which HtmlElement this is. All profileable elements in static screens has a unique enum matching this one.|static_element|Yes|
|screen\_definition\_element|The id of the screen_definition_element.|FK [screen_definition_element](./screen-definition-element.mdx)|No|
|profile\_type|Enum indicating whether this is the default profile (only one), user profile or a common profile. Defined in Profile.h|profile_type|Yes|
|element\_type|What kind of element is this? Static, blogic or extra table?|element_type|Yes|
|owned\_by\_user|The id of the user.|FK [ejuser](./ejuser.mdx)|No|
|config|The actual profile data. Each HtmlElement may choose format. Normally XML.|Clob|Yes|
|filter\_field|Name of field, if any, that is used to filter which profiles should be shown|String(254)|Yes|
|filter\_value|If filter_field is set, then this field is the value that is used to filter which profiles should be shown|String(254)|Yes|
