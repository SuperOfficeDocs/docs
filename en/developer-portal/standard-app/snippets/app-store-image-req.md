**App Store image requirements:**

| Image | Usage | Size<br />(width by height in pixels) |
|-------|-------|--------|
| Home page icon | Preview in the main page | 488 x 488 |
| Detail page icon | Application detail page | 488 x 488 |
| Your company logo | Vendor page (partner profile), shown in a bubble | Square, from 488 x 488 to 1080 x 1080 |

**Accepted file formats:** PNG, JPEG, GIF, WebP, and BMP. Other formats, such as TIFF, TGA, and PBM, are rejected because browsers can't display them.
