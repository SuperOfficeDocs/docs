The description shown in the concent dialog when the admin is prompted to approve the application.

## How to

<GoToAppPage />
2. Select **Configuration**.

3. On the **Authentication** tab, scroll down and update the text in the **Authorize** box.

    ![Edit Authorize field -screenshot][img1]

4. In the **You have unsaved changes** bar in the bottom-right corner, click **Save Settings**.

5. Request to publish the new configuration.
