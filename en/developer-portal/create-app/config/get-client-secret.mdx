## Create a new client secret

Use this when the environment doesn't have a client secret yet.

5. In the **You have unsaved changes** bar in the bottom-right corner, click **Save Settings**.

## Renew a client secret

Use this to replace an existing client secret, for example if it has been lost or compromised, or as part of regular rotation. You no longer need to delete the old secret first.

<GoToAppPage />
2. Select **Configuration**.

3. On the card of the client secret you want to replace, click the renew icon (<i class="ph ph-arrow-clockwise" aria-label="Renew"></i>), next to the trashcan.

4. The **Renew client secret** popup opens with the old description filled in and the warning *The current secret stops working after Publish.* Update the description and expiration if needed, then click **Renew**.

    ![Renew client secret popup -screenshot][img2]

5. The message *New client secret generated. The old one stops working after Publish.* appears at the top of the page, and the card shows the new secret in full.

6. Copy the new secret and store it somewhere safe! You can't look it up in the Developer Portal later.

7. In the **You have unsaved changes** bar in the bottom-right corner, click **Save Settings**.

    ![New client secret generated, with the unsaved changes bar -screenshot][img3]

8. Update your application with the new secret before the new version is published, so that it keeps working when the old secret stops working.

Renewing works the same way in SOD, Stage, and Production.
