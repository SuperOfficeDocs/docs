<Note>
AI services require a separate license. SuperOffice AI is cloud only and is a separate add-on.
</Note>

The introduction of Artificial Intelligence (AI) in SuperOffice gives request handlers / support agents a new set of smart tools to make their workday more efficient.

<Tip>
Do not see these features in a request? Ask your administrator to [enable text analysis][17].
</Tip>

## Request Insight {#sentiment}

Request Insight analyzes the sentiment of an incoming request, so you can prioritize the customer who needs you first.

<Note>
Request Insight requires a Text Services license, or CRM Suite Core.
</Note>

Is the contact happy or angry? If this function is active, incoming email requests are analyzed to determine the mood of the contact. An emoticon below the message indicates the detected sentiment:

* Negative <i class="ph ph-smiley-sad" aria-hidden="true"></i>
* Neutral <i class="ph ph-smiley-meh" aria-hidden="true"></i>
* Positive <i class="ph ph-smiley" aria-hidden="true"></i>

## Summary Assist {#summary}

Summary Assist summarizes the messages in a request so you can act on it without reading the full thread. It appears as an action in the same panel as Reply Assist.

<Note>
Summary Assist requires a Text Services license, or CRM Suite Core.
</Note>

1. In the request panel, select **Summarize**.
2. Review the generated summary of the request's messages.
3. Select **Back** to return to the panel.

## Translation Assist {#translate}

Translation Assist detects the language of an incoming request and offers translation, so you can read and reply to requests in any language.

<Note>
Translation Assist requires a Text Services license, or CRM Suite Core.
</Note>

This functionality automatically detects the language of an incoming request. The detected language is displayed under the message.

If you receive a message in a language you cannot read, you can click the **Translate from** ***language*** below the message. The subject and body of the message is translated and added below the original message.

## Category Insight {#categorization}

Category Insight analyzes incoming email requests and suggests a category based on their content. It does not apply the category automatically.

<Note>
Category Insight requires the SuperOffice AI Platform and a Categorization license, or CRM Suite Growth.
</Note>

If you do not see suggestions, ask your administrator to [train the model and enable suggestions][18].

1. Open an incoming email request and look for a suggested category in the request footer.
1. Review the suggestion. If it fits the request, select the category link to apply it.
1. Check the category on the request. The suggestion disappears after you apply it.

![Suggested category in a request footer -screenshot][img2]

If no category matches, no suggestion appears. You can still choose a category yourself.

## Reply Assist {#reply-assist}

Instead of a blank page, Reply Assist suggests a tailored reply to an incoming service request. It builds the draft from your own CRM content: earlier requests, reply templates, FAQ entries, documents, and, optionally, web content.

As with every SuperOffice AI capability, this is a suggestion for you to approve. Nothing is saved or sent automatically.

<Note>
Reply Assist requires [CRM Suite Plus][8] or above.
</Note>
