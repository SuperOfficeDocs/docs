A *custom object* is a type of record that your administrator defines, such as *Equipment*, *Contract*, or *Car*. Each custom object has its own fields, and can relate to companies, contacts, sales, projects, requests, follow-ups, and other custom objects.

In the database, a custom object is an extra table (also called a *third-party table*). Administrators create custom objects in **Settings and maintenance** > **System design** > **Tables**. See [Add a custom object][2].

## Where to find custom objects {#where}

Custom objects work like the standard records in SuperOffice:

* **Navigator:** Custom objects are listed in the Navigator, each with its own icon. Select a custom object to open its screen with a list of records. TODO(label): confirm whether only custom objects set to show in the Navigator appear here.
* **Main menu:** Select <i class="ph ph-list" aria-label="Main menu"></i> > **Custom objects** to see all custom objects you have access to. TODO(label)
* **New:** Select **New** in the top bar to [create a record][7] of a custom object.
* **Section tabs:** When a custom object relates to a company, contact, sale, project, or request, the related records are shown on a tab on that record. For example, a company shows an **Equipment** tab with the equipment registered for the company.
* **Side panel:** On a section tab with custom objects, select a record to see it in the **Preview** view of the side panel. Select a related record in the preview to go to it.
* **History and favorites:** Records you open are added to your [history][9], and you can [add them as favorites][10].

## Search for custom objects {#search}

You can search for custom objects and create selections and dashboards based on them, in the same way as for companies, contacts, and sales.

* **Find:** In the **Find** screen, select a custom object to search for its records. You can also use a custom object as search criteria when you search for companies, contacts, sales, projects, requests, and follow-ups. For example, find all companies that have equipment of the type *Printer*.
* **Selections:** Save the search as a selection of custom object records. A dynamic selection keeps the list up to date.
* **Dashboards:** Use a custom object as the data source of a dashboard tile. For example, show the number of equipment items per type.

## Tables screen {#tables}

The **Tables** screen in **Settings and maintenance** > **System design** lists the database tables. It shows both standard tables, which are part of SuperOffice, and extra tables, which you create yourself. Custom objects are extra tables.

Here, administrators create custom objects and add fields to them. Only administrators have access to this screen.

Use table folders to organize your custom objects.

## Naming conventions {#conventions}

<Warning>
Choose database table and field names carefully. You cannot change them later.
</Warning>

Use logical names, so it is easy to see what the database contains. The prefixes prevent conflicts with future SuperOffice table and field names. They do not prevent conflicts between custom objects from different third parties.

### Table names

* Must start with **y_**
* May contain only underscores, the letters a to z, and numbers

### Field names

* Must start with **x_**
* Must be unique within the table
* Must be a single word
* May contain only underscores, the letters a to z, and numbers

## Custom objects in web panels {#web-panel}

Before custom objects were available as records in SuperOffice CRM, extra tables were shown through web panels. See [extra tables in web panels][11] in the documentation for version 11.
