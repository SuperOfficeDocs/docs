You can create a record of a custom object from the top bar or from a related record. The fields you see depend on how your administrator set up the custom object.

To create records, your role must have the **Create** permission for the custom object. See [access rights for custom objects][1].

## Create a record from the top bar {#top-bar}

1. Select **New** in the top bar, and then select the custom object. For example, **Lease**.

1. Fill in the fields. Mandatory fields are marked in red.

    * For a relation field, such as **Company**, start typing and select the record from the list. The list shows a preview of each match, so you can select the right one.

1. Select **Save**.

![Lease form with relation fields filled in -screenshot][img2]

## Create a record from a related company or contact {#related}

When a custom object relates to a company, contact, sale, project, or request, the record has a section tab for the custom object. A record you create there is linked automatically.

1. Open the company (or other record) and select the custom object's section tab. For example, **Leases**.

1. Select **Add**.

1. Fill in the fields. The relation to the company is already filled in.

1. Select **Save**.

Some fields may already have values when the form opens. Your administrator can set default values or use a trigger to pre-fill fields.
