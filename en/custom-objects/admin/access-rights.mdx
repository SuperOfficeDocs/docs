You decide per [role][1] what users can do with the records of each custom object. For example, service technicians can update equipment records, while sales representatives can only read them.

The rights apply to all records of the custom object. They are set separately from the [data rights][2] for companies, contacts, sales, and projects.

## Steps

1. <OpenRoles />

1. Choose the **Associates** tab.

1. Select the role in the **Roles** list.

1. Select the **Custom objects** tab. TODO(label)

1. Next to each custom object, select <i class="ph ph-caret-down" aria-label="Chevron"></i> and choose the right:

    | Right | Users with this role can |
    |---|---|
    | None | Not see the custom object or its records |
    | Read | See records |
    | Create | See and create records |
    | Update | See, create, and edit records |
    | Delete | See, create, edit, and delete records |
