Utility class to generate a field for dialog to use in CRMScript triggers.

## Constructors

### EventDataDialogField()

```crmscript
EventDataDialogField
```

Initializes a new instance of the EventDataDialogField class.

## Methods

## addListItem(String)

Adds individual items to list.

```crmscript
Void addListItem(String item)
```

**Returns:** [CRMScript.Global.Void](/en/automation/crmscript/reference/CRMScript.Global.Void)

**Example:**

```crmscript
EventDataDialogDefinition dialog;
EventDataDialogField field;
field.setId("myList");
field.setType("list");
field.addListItem("Value 1");
field.addListItem("Value 2");
dialog.addField(field);
```

## setType(String)

Sets what type of field.

```crmscript
Void setType(String type)
```

**Returns:** [CRMScript.Global.Void](/en/automation/crmscript/reference/CRMScript.Global.Void)

<Note>
Supports:

- label
- text
- integer
- decimal
- checkbox
- date
- datetime
- time
- timeSpan
- list. Note: the "(No Selection)" option can be added by appending "WithNoSelection" to the list name e.g., field.setListName("associateWithNoSelection");
</Note>

**Example:**

```crmscript

field.setType("list");
field.setListName("associate");
print(field.getType());
```
