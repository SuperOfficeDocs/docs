## Feedback

If you want to give documentation feedback, please use the feedback control located at the bottom of each documentation page.

## Documentation Issues

To enter documentation bugs, please create a [new GitHub issue](https://github.com/superofficedocs/docs/issues). Please check if there is an existing issue first.

If you think the issue is with the SuperOffice product itself, please enter issues in the [product support page](https://support.superoffice.com).

## Contributing

To contribute new topics/information or make changes to existing documentation, please read the [Contributing Guideline](https://docs.superoffice.com/contribute).
