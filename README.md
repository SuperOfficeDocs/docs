You've found the SuperOffice documentation GitHub repository, which contains the content for the [SuperOffice documentation][1].

The content is written in Markdown and MDX, and built and hosted by [Mintlify][2]. For an overview of the site itself and how it works, see [About the documentation site][3].

## Feedback

If you want to give documentation feedback, please use the feedback control located at the bottom of each documentation page.

## Documentation issues

To enter documentation bugs, please create a [new GitHub issue][4]. Please check if there is an existing issue first.

If you think the issue is with the SuperOffice product itself, please enter issues in the [product support page][5].

## Contributing

To contribute new topics/information or make changes to existing documentation, please read the [Contributing guideline][6].
