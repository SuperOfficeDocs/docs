## reCAPTCHA-Element hinzufügen

1. Erstellen oder öffnen Sie ein Formular.
1. Wählen Sie **Felder**.
1. Klicken Sie auf **Element hinzufügen**, und wählen Sie **Formularelemente** > **Google reCAPTCHA**.

    ![imagehkoheq.png -screenshot][img1]

Wenn das Element hinzugefügt wurde, können Sie entscheiden, wie Sie den Site key und den Secret key verwenden möchten.

<Note>
Es ist nur möglich, 1 reCAPTCHA pro Formular hinzuzufügen.
</Note>

SuperOffice Online stellt Ihnen Standardschlüssel für reCAPTCHA zur Verfügung, die Ihr Formular vor Robotern schützen. Sie müssen für Site key und Secret key nichts eingeben, es sei denn, Sie möchten ein eigenes reCAPTCHA-Profil erstellen und Statistiken einsehen. Folgen Sie dazu den nachstehenden Schritten, und geben Sie Ihren SiteKey und SecretKey ein. [Statistiken][1] zeigen Ihnen, wie viele Anfragen erfolgreich oder fehlgeschlagen waren, den durchschnittlichen Score, die abgeschlossenen Sitzungen und die durchschnittliche Antwortzeit.

![imagehekct.png -screenshot][img2]

## So erstellen Sie ein Google reCAPTCHA-Profil

Um benutzerdefinierte Schlüssel zu erstellen, melden Sie sich mit einem Google-Konto bei [https://www.google.com/u/0/recaptcha/admin/create][2] an.

1. Geben Sie eine Websitebezeichnung ein.
1. Wählen Sie "reCAPTCHA v2".
1. Und dann das Kontrollkästchen "Ich bin kein Roboter".
1. Fügen Sie die Domain hinzu. Unter "domains" müssen Sie die Domain angeben, auf der das Customer Center (customer.fcgi) ausgeführt wird, oder eine übergeordnete Domain dieser Subdomain.

![imagerlc6j.png -screenshot][img3]

Nachdem Sie auf **Submit** geklickt haben, werden Ihr Site key und Secret key angezeigt:

![imagehn8rh.png -screenshot][img4]
