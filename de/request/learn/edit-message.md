Sie können die Eigenschaften einer Nachricht in einer Anfrage ändern, wenn Sie Eigentümer der Anfrage sind oder das Recht haben, die Anfragen anderer Benutzer zu bearbeiten. Um den Text einer Nachricht zu bearbeiten, muss die [globale Einstellung][2] **Bearbeitung von Nachrichten zulassen** aktiviert sein. Sie ist standardmäßig deaktiviert.

1. [Öffnen Sie die Anfrage][1].
1. Wechseln Sie zur Registerkarte **Nachrichten**.
1. Klicken Sie auf <i class="ph ph-dots-three-circle-vertical" aria-label="Aufgabenmenü"></i> und wählen Sie **Ändern**.
1. Hier haben Sie folgende Optionen:
    * **Nachrichtentext**: Wird nur angezeigt, wenn **Bearbeitung von Nachrichten zulassen** aktiviert ist. In einem Kommentar können Sie [Mitarbeiter erwähnen][3].
    * **Verfasser**: Zeigt den Namen der Person, die die Nachricht erstellt hat. Wird nur angezeigt, wenn Sie Service-Administrationsrechte haben.
    * **Aufgewendete Zeit**: Zeigt die für diese Nachricht aufgewendete Zeit an.
    * **Zugriffsstufe**: Die Zugriffsstufe für diese Nachricht. Sie können zwischen **Extern** und **Intern** wählen.
    * **Benutzerdefinierte Felder**: Alle benutzerdefinierten Felder für Nachrichten.
    * **Anlagen**: Falls die Nachricht Anhänge enthält, werden diese in dieser Tabelle angezeigt. Mit Service-Administrationsrechten können Sie vorhandene Anhänge löschen, aber keine neuen hinzufügen.

1. Klicken Sie auf **Speichern**, wenn Sie fertig sind, oder auf **Abbrechen**, um die Änderungen zu verwerfen. Mit Service-Administrationsrechten können Sie die gesamte Nachricht auch löschen, indem Sie auf **Löschen** und dann auf **OK** klicken.
