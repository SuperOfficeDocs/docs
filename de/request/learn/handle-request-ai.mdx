<Note>
Für KI Services ist eine separate Lizenz erforderlich. SuperOffice AI steht nur in der Cloud zur Verfügung und ist ein separates Add-on.
</Note>

Die Einführung von Künstlicher Intelligenz (KI) in SuperOffice bietet Bearbeitern von Anfragen/Supportmitarbeitern ein neues Set intelligenter Tools für einen effizienteren Arbeitstag.

<Tip>
Sehen Sie diese Funktionen nicht in einer Anfrage? Bitten Sie Ihren Administrator, die Textanalyse zu aktivieren.
</Tip>

## Request Insight {#sentiment}

Request Insight analysiert das Sentiment einer eingehenden Anfrage, damit Sie den Kunden priorisieren können, der Sie am dringendsten braucht.

<Note>
Request Insight erfordert eine Text Services-Lizenz oder CRM Suite Core.
</Note>

Ist die Person glücklich oder wütend? Wenn diese Funktion aktiv ist, werden eingehende E-Mail-Anfragen analysiert, um die Stimmung der Person festzustellen. Ein Emoticon unter der Nachricht zeigt die erkannte Stimmung an:

* Negatives <i class="ph ph-smiley-sad" aria-hidden="true"></i>
* Neutrales <i class="ph ph-smiley-meh" aria-hidden="true"></i>
* Positives <i class="ph ph-smiley" aria-hidden="true"></i>

## Summary Assist {#summary}

Summary Assist fasst die Nachrichten einer Anfrage zusammen, damit Sie handeln können, ohne den gesamten Verlauf zu lesen. Die Funktion erscheint als Aktion im selben Bereich wie Reply Assist.

<Note>
Summary Assist erfordert eine Text Services-Lizenz oder CRM Suite Core.
</Note>

1. Wählen Sie im Anfragenbereich **Zusammenfassen** aus.
2. Prüfen Sie die generierte Zusammenfassung der Nachrichten der Anfrage.
3. Wählen Sie **Zurück**, um zum Bereich zurückzukehren.

## Translation Assist {#translate}

Translation Assist erkennt die Sprache einer eingehenden Anfrage und bietet eine Übersetzung an, damit Sie Anfragen in jeder Sprache lesen und beantworten können.

<Note>
Translation Assist erfordert eine Text Services-Lizenz oder CRM Suite Core.
</Note>

Mit dieser Funktion wird die Sprache einer eingehenden Anfrage automatisch erkannt. Die erkannte Sprache wird unter der Nachricht angezeigt.

Wenn Sie eine Mitteilung in einer Sprache erhalten, die Sie nicht lesen können, können Sie unter der Mitteilung auf **Übersetzen aus** ***Sprache*** klicken. Betreff und Text der Nachricht werden übersetzt und unter der ursprünglichen Nachricht hinzugefügt.

## Category Insight {#categorization}

Category Insight verwendet ein trainiertes Modell, um anhand des Nachrichteninhalts eine Kategorie für eingehende E-Mail-Anfragen vorzuschlagen. Der Vorschlag wird erst angewendet, wenn Sie ihn bestätigen.

<Note>
Category Insight erfordert die SuperOffice AI Platform und eine Categorization-Lizenz oder CRM Suite Growth. Sie ist nur in CRM Online verfügbar.
</Note>

Sehen Sie keine Vorschläge? Bitten Sie Ihren Administrator, [das Modell zu trainieren und Vorschläge zu aktivieren][18].

1. Öffnen Sie eine eingehende Anfrage und suchen Sie in der Fußzeile nach der vorgeschlagenen Kategorie.
1. Prüfen Sie den Vorschlag und wählen Sie den Kategorielink aus, wenn die Kategorie zur Anfrage passt.
1. Prüfen Sie die aktualisierte Kategorie. Nach dem Anwenden verschwindet der Vorschlag.

![Vorgeschlagene Kategorie in einer Anfrage -screenshot][img2]

Wenn keine Kategorie passt, wird kein Vorschlag angezeigt. Sie können die Kategorie weiterhin selbst auswählen.

## Reply Assist {#reply-assist}

Anstatt einer leeren Seite schlägt Reply Assist eine passende Antwort auf eine eingehende Anfrage vor. Der Entwurf basiert auf Ihren eigenen CRM-Daten: frühere Anfragen, Antwortvorlagen, FAQ-Einträge, Dokumente und optional Webinhalte.

Wie bei jeder SuperOffice KI-Funktion handelt es sich um einen Vorschlag, den Sie genehmigen müssen. Es wird nichts automatisch gespeichert oder gesendet.

<Note>
Reply Assist erfordert [CRM Suite Plus][8] oder höher.
</Note>
