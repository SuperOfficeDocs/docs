Wenn eine Nachricht zwei verschiedene Anliegen enthält, die getrennt bearbeitet werden sollten, können Sie die Nachricht aufteilen und daraus eine neue Anfrage erstellen. Dies ist beispielsweise sinnvoll, wenn eine Nachricht sowohl eine technische Frage als auch eine Frage zur Rechnungsstellung enthält, da diese beiden Themen von unterschiedlichen Abteilungen bearbeitet werden.

## Schritte

1. [Öffnen Sie die Anfrage][1].

1. Klicken Sie auf der Registerkarte **Nachrichten** auf <i class="ph ph-dots-three-circle-vertical" aria-label="Aufgabenmenü"></i> neben der Nachricht, die Sie aufteilen möchten, und wählen Sie **Nachricht aufteilen** aus.

1. Geben Sie in der Anzeige **Nachricht aufteilen** im Feld **Titel** einen aussagekräftigen Namen für die neue Anfrage ein.

1. Wählen Sie im Feld **Kategorie** eine Kategorie aus.

1. Wählen Sie im Feld **Eigentümer** eine der folgenden Optionen:
    * Um die Anfrage einer bestimmten Person zuzuweisen, wählen Sie den gewünschten Namen aus.
    * **(Automatische Zuweisung):** Wenn diese Option ausgewählt ist, weist das System die Anfrage gemäß den geltenden Zuweisungsregeln zu.
    * **(Nicht zugeordnet):** Sie können die Anfrage auch niemandem zuweisen. Die Mitglieder der zuständigen Kategorie sind dann für die Bearbeitung der Anfrage verantwortlich.

1. Im Feld **Priorität** können Sie zwischen **Niedrig**, **Mittel** und **Hoch** wählen oder die Priorität automatisch vom System festlegen lassen. Dies kann zum Beispiel anhand der Eskalationsstufen erfolgen, die für verschiedene Kunden festgelegt sind.

1. Wählen Sie im Feld **Zugriffsstufe** eine der folgenden Optionen:
    * **Extern:** Wählen Sie diese Option, wenn der Kunde über ein Kundenzentrum Zugriff auf die Anfrage haben soll.
    * **Intern:** Wählen Sie diese Option, wenn der Kunde keinen Zugriff auf die Anfrage haben soll.

1. <StepSplitStatus />

1. (Falls relevant) Wählen Sie unter **Anhänge zur neuen Anfrage verschieben** die Anhänge aus, die in die neue Anfrage verschoben werden sollen. Die Anhänge werden aus der bestehenden Anfrage gelöscht.

1. Gehen Sie zur Registerkarte **Nachrichten** und bearbeiten Sie die Nachrichtentexte für die bestehende und die neue Anfrage.

1. Klicken Sie auf **OK**. Die Nachricht wird aufgeteilt, und die neue Anfrage wird geöffnet.
