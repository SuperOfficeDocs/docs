Alle in SuperOffice erfassten Anfragen haben einen Status wie **Geöffnet**, **Geschlossen** oder **Aufgeschoben**. Wenn Sie im Navigator und in der Registerkarte **Anfragestatus** **Anfrage** auswählen, können Sie die bereits im System festgelegten Anfragenstatus sehen und zusätzliche Status erstellen. Ein Anfragestatus muss mit einem internen Status des Systems wie **Geöffnet** oder **Geschlossen** verknüpft werden. Jeder interne Status muss mit mindestens einem Anfragestatus verknüpft sein.

Sie könnten beispielsweise den neuen Status "Warten auf Antwort" als Variante zu **Geschlossen** oder **Geöffnet** erstellen, je nachdem, wie das System den Status intern verarbeiten soll. Sie können diesen Statuswerten auch logische Funktionen zuordnen, um Ihre Branchenprozesse zu vereinfachen.

## Einstellungen

| Einstellung | Beschreibung |
|---|---|
| Name | Der Name des Anfragestatus. Standardmäßig hat jeder interne Status einen Anfragestatus mit demselben Namen. |
| Interner Status | Die internen Statuswerte des Systems. Jeder interne Status muss mit mindestens einem Anfragestatus verknüpft sein. Die Systemstatuswerte **Zusammengeführt** und **Gelöscht** werden nur für zusammengeführte bzw. gelöschte Anfragen verwendet und werden für die Benutzer nicht angezeigt. |
| Standard | Gibt an, ob es sich um einen Standardstatus für den internen Status handelt. |
| Warteschlangenstatus | Gibt an, ob Anfragen mit diesem Status in die Warteschlange gestellt werden sollen. Relevant, wenn Sie die Funktion **Nächste Anfrage in der Warteschlange anzeigen** verwenden. |
| Zeit nachverfolgen als | Wird verwendet, um den Zeitverbrauch in mehreren Stufen der Anfragenverwaltung zu melden. Das System berechnet den Zeitverbrauch bezüglich der definierten "Geschäftszeiten" sowie des gesamten 24-Stunden-Zeitraums. Wählen Sie aus: in der Warteschlange und in Erwartung der Verarbeitung; in der Phase der internen Entscheidung; in der Phase der externen Entscheidung |
| [Optionen zum Aufschieben][8] | Nur für Status mit dem internen Status **Aufgeschoben**. Die Optionen, aus denen Benutzer wählen können, wenn sie eine Anfrage aufschieben. |

## Standardstatus für neue Anfragen und Antworten {#default}

Wenn Sie eine Anfrage erstellen, wird ihr Status in dieser Reihenfolge festgelegt:

1. Der **Standardstatus für neue Anfragen** der [Kategorie][1], sofern der Anfragetyp diesen Status zulässt.
1. Der **Standard-Status** des [Anfragetyps][2].
1. Ihre Einstellung **Standardstatus für neue Anfragen**, sofern der Anfragetyp diesen Status zulässt.
1. Wenn nichts davon zutrifft, wird die Anfrage mit dem Status **Geöffnet** gespeichert.

Der Status wird festgelegt, wenn die Registerkarte **Neue Anfrage** geöffnet wird. Wenn Sie danach die Kategorie oder den Anfragetyp ändern, ändert sich der Status nicht.

Wenn Sie auf eine Anfrage antworten, wird der Status in dieser Reihenfolge festgelegt:

1. Der **Standardstatus für neue Nachrichten** der Kategorie, sofern der Anfragetyp diesen Status zulässt.
1. Ihre Einstellung **Standardstatus für neue Nachrichten**, sofern der Anfragetyp diesen Status zulässt.
1. Wenn keines davon zutrifft, bleibt der Status unverändert.

Die Liste **Verfügbare Statuskategorien** eines Anfragetyps schränkt die Standardstatus ein. Ein Standardstatus einer Kategorie oder Einstellung, der nicht in dieser Liste enthalten ist, wird übersprungen.

Ein Standardstatus kann ein aufgeschobener Status mit einer Aufschuboption wie **Um eine Woche aufschieben** sein. Die Option stammt aus derselben Einstellung wie der Status, und die Registerkarte **Neue Anfrage** zeigt sie an, bevor Sie speichern.

<Note>
[Aufgeteilte Anfragen][4] und [aufgeteilte Nachrichten][5] behalten den Status und das Aufschubdatum der ursprünglichen Anfrage. Anfragen, die aus eingehenden E-Mails erstellt werden, erhalten den Status **Geöffnet**. Wenn bei einem [E-Mail-Filter][3] **Anfrage abschließen** aktiviert ist, erhalten sie stattdessen den Status **Geschlossen**. In diesen Fällen werden keine Standardstatus verwendet.
</Note>

## Optionen zum Aufschieben {#postpone}

Jeder Status mit dem internen Status **Aufgeschoben** hat eine eigene Liste von Optionen. Benutzer sehen die Liste, wenn sie [eine Anfrage aufschieben][6]. So können Sie die Intervalle anbieten, die Ihr Team verwendet, und die übrigen ausblenden.

![Optionen zum Aufschieben bei einem Anfragestatus mit dem internen Status Aufgeschoben -screenshot][img1]

| Spalte | Beschreibung |
|---|---|
| Option | Der Name, den Benutzer im Menü zum Aufschieben sehen. |
| Regel | Wie der Zeitpunkt berechnet wird, zum Beispiel **Nach einem Zeitintervall** oder **Nächster Werktag**. |
| Wert | Das Intervall oder die Uhrzeit, zum Beispiel **24 Stunden** oder **Mo 08:00**. |
| Arbeitszeit | Ob Wochenenden und Zeiten außerhalb der Arbeitszeiten übersprungen werden. |
| Aktiv | Ob die Option im Menü zum Aufschieben angezeigt wird. |

Sie können **Standard**-Optionen deaktivieren, aber nicht bearbeiten oder löschen. **Angegeben** ist nicht in der Liste. Die Option steht im Menü zum Aufschieben immer an letzter Stelle und kann nicht deaktiviert werden. Sie können auch [eigene Optionen hinzufügen][9].

Ein Support-Team fügt zum Beispiel **Morgen Nachmittag** (**Nächster Werktag** um 13:00) hinzu und deaktiviert **Um einen Monat aufschieben**, weil es diese Option nie verwendet.

Werktage und Zeiten außerhalb der Arbeitszeiten richten sich nach den Öffnungszeiten der [Priorität][7] der Anfrage (**Zeitrahmen**), und die Feiertage der Priorität werden übersprungen. Wenn keine Öffnungszeiten festgelegt sind, gelten Montag bis Freitag als Werktage.
