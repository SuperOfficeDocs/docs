<Note>
Für Zusatztabellen ist der CRM Suite **Growth**-Plan oder höher erforderlich, oder eine benutzerplanbasierte Lizenz mit [Development Tools][8].

Mit einer benutzerplanbasierten Lizenz sind Zusatztabellen in SuperOffice Service und in SuperOffice CRM über [Webpanels](#web-panel) verfügbar. Um sie als benutzerdefinierte Objekte in SuperOffice CRM zu verwenden, nehmen Sie am [Pilotprogramm für benutzerdefinierte Objekte][9] teil.
</Note>

Sie speichern Ihre eigenen Datentypen in Zusatztabellen. Sie erstellen die Tabelle unter **Tabellen** und [fügen ihr Felder hinzu][1].

In der CRM Suite wird eine Zusatztabelle zu einem [benutzerdefinierten Objekt][3], das sich wie Firmen und Verkäufe verhält. Die Schritte zum Erstellen der Tabelle sind unabhängig von der Lizenz dieselben. Tabelleneigenschaften und Rollenberechtigungen bestimmen, wie Benutzer sie anzeigen und bearbeiten.

## Namenskonventionen

<Warning>
Wählen Sie die Namen von Datenbanktabellen sorgfältig aus. Sie **können sie später nicht ändern**.
</Warning>

Verwenden Sie logische Namen, damit leicht zu erkennen ist, was die Datenbank enthält. Das Präfix **y_** verhindert Konflikte mit zukünftigen SuperOffice-Tabellennamen. Es verhindert keine Konflikte zwischen Zusatztabellen verschiedener Drittanbieter.

* Muss mit **y_** beginnen
* Darf nur Unterstriche, die Buchstaben a bis z und Zahlen enthalten

## Schritte

1. <GotoTables />

1. Klicken Sie auf **Neue Tabelle**.

    ![Ansicht Tabellen mit der Schaltfläche Neue Tabelle -screenshot][img1]

1. In der Ansicht **Eigenschaften der Tabelle** konfigurieren Sie die neue Tabelle.

    * Geben Sie einen *Namen* ein, der als Bezeichnung verwendet wird.
    * Geben Sie eine *Beschreibung* ein, die erklärt, wofür die Tabelle verwendet wird, damit andere Administratoren sie verstehen.
    * Geben Sie eine *Datenbanktabelle* ein, die mit **y_** beginnt, um sie im Schema zu identifizieren.
    * Damit Benutzer das benutzerdefinierte Objekt finden, [wählen Sie ein Symbol aus](#icon) und [lassen Sie die Tabelle im Navigator und unter Suchen anzeigen](#navigator).
    * Optional setzen Sie [weitere Eigenschaften](#properties).

    <Note>
    Einige Tabelleneigenschaften können nicht eingestellt werden, bis Sie Felder hinzugefügt haben.
    </Note>

1. Klicken Sie auf **OK**, um die neue Tabelle zu speichern (führt `create table y_mynewtable ...` aus).

1. [Fügen Sie Felder zu Ihrer neuen Tabelle hinzu][1].

1. Wählen Sie den Tabellennamen in der Liste aus, um die Ansicht **Eigenschaften der Tabelle** erneut zu öffnen. Da die Tabelle jetzt Felder hat, können Sie diese anstelle der ID verwenden:

    * Wählen Sie unter **Sortierreihenfolge** das Feld aus, nach dem die Einträge sortiert werden.
    * Wählen Sie unter **Anzeigefeld** das Feld aus, das einen Eintrag identifiziert, wenn die Tabelle in einer anderen Tabelle angezeigt wird.

    ![Liste Anzeigefeld mit den Feldern der Tabelle -screenshot][img4]

1. Klicken Sie auf **NetServer neu starten**. Wenn Travel aktiviert ist, sehen Sie auch eine Nachricht, dass eine neue Travel-Datenbank generiert werden muss.

1. Wenn die Tabelle ein benutzerdefiniertes Objekt ist, [geben Sie Rollen Zugriff](#access-rights) darauf.

Die Tabelle ist einsatzbereit. In der CRM Suite können Sie optional das Layout des benutzerdefinierten Objekts im [Ansichtsdesigner][5] anpassen.

## Tabelleneigenschaften {#properties}

| Eigenschaft | Beschreibung |
|---|---|
| Order | Um die Tabelle in einem vorhandenen Ordner abzulegen, wählen Sie einen Ordner aus der Liste aus. |
| Name | Die Bezeichnung der Tabelle in der Benutzeroberfläche. |
| Beschreibung | Wofür die Tabelle verwendet wird. Füllen Sie das Feld aus, damit andere Administratoren die Tabelle verstehen. |
| Datenbanktabelle | Der Name der Tabelle in der Datenbank. Kann nur bei der Erstellung festgelegt werden und **kann nicht geändert werden**. |
| Kopfzeile für Suche | Die Kopfzeile wird für diese Tabelle in der Ansicht Suchen verwendet. |
| Kopfzeile für Datenanzeige | Die Kopfzeile wird zur Anzeige eines Eintrags in dieser Tabelle verwendet. |
| Kopfzeile für neuen Eintrag | Die Kopfzeile wird zum Erstellen eines neuen Eintrags in dieser Tabelle verwendet. |
| Kopfzeile für Datenbearbeitung | Die Kopfzeile wird für die Bearbeitung eines Eintrags in dieser Tabelle verwendet. |
| Reihenfolge | Die Spalte, nach der die Tabelle sortiert wird. Wenn Sie **Absteigend** aktivieren, werden die Werte in absteigender Reihenfolge sortiert. Für Zahlenwerte bedeutet dies, dass der höchste Wert ganz oben in der Tabelle angezeigt wird. Die Tabelle muss Felder enthalten, bevor Sie hier etwas auswählen können. |
| Anzeigefeld | Wenn Daten aus dieser Tabelle in einer anderen Tabelle (eine Beziehung) angezeigt werden sollen, müssen Sie hier auswählen, welches Feld in der anderen Tabelle angezeigt werden soll. Die Tabelle muss Felder enthalten, bevor Sie hier etwas auswählen können. |
| Übergeordnetes Feld | Dieses Feld kommt in Verbindung mit Tabellen mit hierarchischer Struktur zum Einsatz. |
| Vollständiger Name | Für hierarchisch strukturierte Tabellen können Sie hier ein Feld angeben, in das automatisch der vollständige Name des Eintrags eingefügt wird. Der Name wird aus dem Namensfeld des Eintrags und aller übergeordneten Einträge abgeleitet. |
| ID-Feld ausblenden | Wenn diese Option ausgewählt ist, wird das ID-Feld bei der Auflistung von Einträgen in der Tabelle nicht angezeigt. |
| Tabelle ausblenden | Wenn diese Option aktiviert ist, ist die Tabelle nicht über das **Systemdesign** > **Tabellen** sichtbar. |
| Tabelle in Suche anzeigen | Wenn diese Option aktiviert ist, können Benutzer in **Suchen** nach benutzerdefinierten Objekten suchen. |
| [Im Navigator anzeigen](#navigator) | Wenn diese Option aktiviert ist, wird die Tabelle im Navigator und unter **Neu** aufgelistet. |
| [Symbol](#icon) | Das Symbol, das für die Tabelle im Navigator und an anderen Stellen angezeigt wird. |
| Batch-Webhook im Dienst aktivieren | Wenn ausgewählt, aktivieren Batch-Updates auf dieser Tabelle [Webhooks][2]. |

## Symbol auswählen {#icon}

Das Symbol wird im Navigator, in der Liste der benutzerdefinierten Objekte, in Kontextmenüs, in der Webhook-Ereignisliste und im Ansichtsdesigner angezeigt.

1. Öffnen Sie die Tabelleneigenschaften und klicken Sie auf **Icon auswählen**.

1. Wählen Sie im Dialogfeld **Icon auswählen** ein Symbol aus:

    * **Standard-Icons:** eine Auswahl gängiger Symbole.
    * **Vollständige Icon-Bibliothek:** Durchsuchen Sie die gesamte Bibliothek oder nach Kategorie.
    * **Benutzerdefinierte Icons:** Laden Sie Ihre eigene SVG-Datei hoch, bis zu 50 KB.

1. Klicken Sie auf **Icon anwenden**.

Um zum Standardsymbol zurückzukehren, klicken Sie auf **Icon entfernen**.

![Dialogfeld Icon auswählen mit den Registerkarten Standard-Icons, Vollständige Icon-Bibliothek und Benutzerdefinierte Icons -screenshot][img2]

## Tabelle im Navigator und unter Suchen anzeigen {#navigator}

Die Tabelle kann im Navigator und unter **Neu** in der oberen Leiste aufgelistet werden. Wählen Sie dazu **Im Navigator anzeigen** in den Tabelleneigenschaften aus.

Damit Benutzer in **Suchen** nach benutzerdefinierten Objekten suchen können, wählen Sie zusätzlich **Tabelle in Suche anzeigen** aus.

![Tabelle in Suche anzeigen, Im Navigator anzeigen und ein Symbol in den Tabelleneigenschaften ausgewählt -screenshot][img3]

## Rollen Zugriff geben {#access-rights}

Benutzer können ein benutzerdefiniertes Objekt nur sehen und damit arbeiten, wenn ihre Rolle ihnen Zugriff gibt. Nachdem Sie die Tabelle erstellt und ihre Felder hinzugefügt haben, legen Sie das Recht für jede Rolle fest, die sie verwenden soll.

1. <OpenRoles />

1. Wählen Sie eine Rolle aus der Liste aus.

1. Wechseln Sie zur Registerkarte **Rechte für benutzerdefinierte Objekte**.

1. Wählen Sie in der Liste **Berechtigung** neben dem benutzerdefinierten Objekt aus, was Benutzer mit dieser Rolle tun können: **Read**, **Create**, **Update** oder **Delete**.

Welche Möglichkeiten jede Berechtigung bietet, lesen Sie unter [Datenrechte für benutzerdefinierte Objekte][4].

## Tabelle in einem Webpanel anzeigen {#web-panel}

Mit einer benutzerplanbasierten Lizenz zeigen Sie Zusatztabellen in SuperOffice CRM über Webpanels an. Um die entsprechenden Zugriffsrechte festzulegen, muss der Benutzer einer Rolle angehören, die über die Funktionsrechte **List tables** und **Edit tables** verfügt.
