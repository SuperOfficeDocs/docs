Bevor Benutzer die KI-Funktionen von SuperOffice nutzen können, muss ein Administrator die KI-Funktionen für die Organisation aktivieren. Einige Funktionen, wie KI-Agenten, erfordern eine zusätzliche Einrichtung.

## KI-Funktionen aktivieren

1. Gehen Sie zu **Einstellungen und Verwaltung** > **Einstellungen** > **Globale Einstellungen** > **KI**.
1. Setzen Sie **KI-Funktionen in SuperOffice aktivieren** auf **Ja**.
1. Klicken Sie auf **Speichern**.

![KI-Funktionen in SuperOffice aktivieren auf Ja gesetzt, hervorgehoben in den globalen KI-Einstellungen -screenshot][img1]

## Textanalyse aktivieren {#enable-text-analysis}

1. Öffnen Sie **Einstellungen und Verwaltung**.
1. Wählen Sie **KI-Services** im Navigator aus.
1. Aktivieren Sie unter **Textanalyse** die Kontrollkästchen für die Funktionen, die Sie nutzen möchten: **Spracherkennung**, **Nachricht übersetzen** und **Sentiment-Analyse**.

    ![Kontrollkästchen für die Textanalyse in den KI-Services -screenshot][img2]

## Globale KI-Einstellungen {#global}

Diese Einstellungen gelten für das gesamte System. Um sie zu ändern, gehen Sie zu **Einstellungen und Verwaltung** > **Einstellungen** > **Globale Einstellungen** und suchen Sie den Abschnitt **KI**.

| Einstellung | Funktion |
|---|---|
| KI-Funktionen in SuperOffice aktivieren | Zeigt die KI-Schaltflächen und -Bereiche in SuperOffice an. Bei **Nein** werden sie ausgeblendet. Der Standardwert ist **Ja**. |
| Leadfeeder-Nutzung zulassen | Ermöglicht es Agenten, Firmen mit Leadfeeder zu prüfen und anzureichern. |
| Kontaktanreicherung zulassen | Ermöglicht es dem Data Quality Agent, beim Anreichern von Firmen Personen hinzuzufügen und zu aktualisieren. Bei **Nein** können Benutzer die Option **Kontakte anreichern** des Agenten nicht aktivieren. Dies gilt auch für die Kontaktanreicherung außerhalb der Agenten. Der Standardwert ist **Nein**. |
| Maximale Nutzung von KI-Credits | Die Gesamtzahl der KI-Credits, die verbraucht werden können. Agenten erstellen keine Aufgaben mehr, wenn die Nutzung das Limit erreicht. |
| Data Quality Agent aktivieren, Duplicate Agent aktivieren, Lead Agent aktivieren, Sales Assistant Agent aktivieren | Aktiviert oder deaktiviert jeden Agenten für alle Benutzer. Bei **Nein** erstellt der Agent keine Aufgaben mehr. |
| Credit-Limit Data Quality Agents, Credit-Limit Duplicate Agents, Credit-Limit Lead Agents, Credit-Limit Sales Assistant Agents, Credit-Limit Leadfeeder | Das Credit-Limit für jeden Agenten und für Leadfeeder. Ein Agent erstellt keine Aufgaben mehr, wenn er sein Limit erreicht. |

<Tip>
Die Agentenschalter, Credit-Limits und zusätzlichen Credit-Pakete lassen sich einfacher auf der Registerkarte [Agent-Limits][5] verwalten, die auch die in diesem Monat verbrauchten Credits anzeigt.
</Tip>

Der Abschnitt **SuperOffice Workspace Assist** enthält eine Einstellung:

| Einstellung | Funktion |
|---|---|
| Workspace Assistant Zugriff auf das Web erlauben | Ermöglicht es [Workspace Assist][6], Informationen aus dem Web in seinen Antworten zu verwenden. |

## KI-Einstellungen pro Benutzer {#preferences-tab}

Diese Einstellungen können für die gesamte Datenbank, für eine Gruppe oder für einen einzelnen Benutzer festgelegt werden. Benutzer können für jede von ihnen auch eine eigene Einstellung haben. Wie Ebenen funktionieren, erfahren Sie unter [Ebenen für Einstellungsoptionen][7].

1. Gehen Sie zu **Einstellungen und Verwaltung** > **Einstellungen** > **Einstellungen**.
1. Wählen Sie **KI** in der Liste der Einstellungsgruppen aus.
1. Wählen Sie eine Einstellung aus und fügen Sie dann unter **Aktive Einstellungen** deren Einstellungen hinzu oder ändern Sie sie.

| Einstellung | Funktion |
|---|---|
| Antwort auf eine Nachricht automatisch generieren | Erstellt einen Vorschlag von [Reply Assist][8], wenn ein Benutzer bei einer Anfrage auf **Antworten** oder **Allen antworten** klickt. |
| KI-Agenten aktivieren | Ermöglicht es Benutzern, eigene [KI-Agenten][2] einzurichten. Bei **Nein** wird das Symbol **Agenten** im Navigator ausgeblendet. Der Standardwert ist **Ja**. |
| MCP-Zugriffskontrolle | Legt fest, was [MCP Connect][3]-Clients in SuperOffice tun können: lesen und aktualisieren (**Alle**, der Standardwert), nur lesen oder nichts. |
| KI-Vorschlag von Reply Assist anzeigen | Zeigt den Vorschlag von [Reply Assist][8] an, wenn ein Benutzer auf eine Anfrage antwortet. |
