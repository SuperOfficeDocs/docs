Check that these requirements are met before you start the setup. Missing requirements and skipped preparations are the most common cause of a failed or incomplete integration.

## Subscriptions

* **Visma Net Financials:** an active subscription
* **SuperOffice CRM:** CRM Suite Core or higher. For the features in each CRM Suite, see [What's included per CRM Suite][2].

## Visma Net integration user

The integration needs a dedicated Visma Net user with these roles:

* **Financials API user**
* **Sales Creator (neXtGen)**

You create this user in [Set up Visma Net][3].

## SuperOffice user rights

Users who need to manually push data to Visma Net must have **edit rights** on the relevant card:

| Action | Required right |
|---|---|
| Create Customer in Visma Net | Edit right on Company card |
| Create/Update Contact in Visma Net | Edit right on Contact card |
| Create Order in Visma Net | Edit right on Sale card |

Users without edit rights won't see the action buttons. Assign the admin screen layouts only to groups that need them.
