This page lists the Visma Net fields that DataBridge supports. You choose which of these fields to use when you configure a DataBridge integration. Field names are the names that DataBridge shows in the user interface.

* **Export:** Visma Net is the source. DataBridge reads the fields from Visma Net and writes them to SuperOffice.
* **Import:** Visma Net is the destination. DataBridge writes the fields to Visma Net.

## Entities per direction {#entities}

| Entity | Export | Import |
|---|---|---|
| Customer | Yes | Yes |
| Vendor (supplier) | Yes | Yes |
| Contact | Yes | Yes |
| Inventory (product) | Yes | No |
| Sales Price | Yes | No |
| Sales Order and Sales Order Lines | Yes | Yes |
| Location | Yes | No |
| Project | Yes | Yes |
| AR Invoice and AR Invoice Line | No | Yes |

<Note>
Sales Order and Sales Order Lines are only available when your Visma Net environment has the Sales module.
</Note>

## Fields per entity {#fields}

Select the **Export** or **Import** tab, and find the entity. Each table lists the fields of one entity, grouped by field group. To find a field on this page, use the search of your browser (Ctrl+F) or the search of this site.

In the field names, a slash separates related fields. For example, **Customer Class ID/Description** stands for the two fields Customer Class ID and Customer Class Description. Names such as **Address Line 1-3** stand for a series of fields. In the import tables, the **Remark** column shows **Key** for the field that DataBridge uses to find an existing record, and **Required** for a field that Visma Net needs to create a record.
