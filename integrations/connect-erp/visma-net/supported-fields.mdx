This page lists the Visma Net fields that DataBridge supports. You choose which of these fields to use when you configure a DataBridge integration. Field names are the names that DataBridge shows in the user interface.

* **Export:** Visma Net is the source. DataBridge reads the fields from Visma Net and writes them to SuperOffice.
* **Import:** Visma Net is the destination. DataBridge writes the fields to Visma Net.

## Entities per direction {#entities}

| Entity | Export | Import |
|---|---|---|
| Customer | Yes | Yes |
| Vendor (supplier) | Yes | Yes |
| Contact | Yes | Yes |
| Inventory (product) | Yes | No |
| Sales Price | Yes | No |
| Sales Order and Sales Order Lines | Yes | Yes |
| Location | Yes | No |
| Project | Yes | Yes |
| AR Invoice and AR Invoice Line | No | Yes |

<Note>
Sales Order and Sales Order Lines are only available when your Visma Net environment has the Sales module.
</Note>

## Search and filter the fields {#fields}

Type in the search box to find a field. All the words that you type must match the field name, the entity, or the field group. For example, **customer email** finds the email fields of the Customer entity. Use **Direction** and **Entity** to narrow the list, and select a column header to sort.

In the field names, a slash separates fields that come as a pair. For example, **Customer Class ID/Description** stands for the two fields Customer Class ID and Customer Class Description. Names such as **Address Line 1-3** stand for a series of fields. In the import fields, **Key** marks the field that DataBridge uses to find an existing record, and **Required** marks a field that Visma Net needs to create a record.
