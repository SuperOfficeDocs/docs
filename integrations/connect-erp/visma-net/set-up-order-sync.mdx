<Note>
Order sync is available only in **CRM Suite Growth and higher**. Skip these steps for Core.
</Note>

Order sync synchronizes sales orders in both directions:

* From SuperOffice to Visma Net on demand, when a user clicks **Create Order in Visma Net** on the Sale card.
* From Visma Net to SuperOffice every hour, for orders that originate in Visma Net.

## 1. Create user-defined field on the Sale card

Go to **Settings and maintenance** > **Fields** > **Sale** > **Add** and create the following field. Set it to **Read only**.

| # | Field name | Type | Prog ID |
|---|---|---|---|
| 1 | ERP Order Number | Short text | `SALEERPORDERNUMBER` |

After adding the field, click **Publish**.

## 2. Add the Order CRMScript

The CRMScript allows users to manually push a sale from SuperOffice to Visma Net as a sales order.

1. Go to **Settings and maintenance** > **CRMScript** > **New script**.
1. Open the **Order to Visma Net** *.txt* file from *crmscripts-visma-net.zip* and paste the content into the [script editor][6].
1. Set the configuration variables at the top of the script:

    | Variable | Value |
    |---|---|
    | `erpPlatform` | The ERP name shown to users in dialogs, for example `"Visma Net"` |
    | `instantJobUrl` | Leave empty for now. You'll complete this in [Add the Instant Job URL to the CRMScript](#6-add-the-instant-job-url-to-the-crmscript) |
    | `allowOnlySaleWithStatusSold` | `true` to allow only sales with status **Sold** to be pushed; `false` to allow all statuses |

1. Save the script.

<Tip>
Keep `allowOnlySaleWithStatusSold = true` to prevent accidental order creation in Visma Net from sales that don't have the status **Sold**.
</Tip>

## 3. Create the Sale card screen layouts

### Standard layout

1. Go to **Settings and maintenance** > **Screen designer** > **Sale**.
1. [Create a new layout][4] for all users.
1. Add a new tab **ERP (Visma Net)** with the **ERP Order Number** field.
1. Save and publish the layout.

![Sale card: standard layout with ERP (Visma Net) tab showing ERP Order Number -screenshot][img1]

### Admin layout

1. Create a second layout for users with edit rights.
1. Add a button executing the **Order to Visma Net** CRMScript, labeled **Create Order in Visma Net**.
1. Add a URL link to the corresponding Visma Net sales order screen.
1. Save and publish the layout.

![Sale card: admin layout with Create Order in Visma Net button -screenshot][img2]

<Warning>
Assign the admin layout only to user groups that should be able to push data to Visma Net. This prevents accidental data creation by other users.
</Warning>

## 4. Create the product selection

DataBridge uses this selection as the field template for the **Visma Net Sales Orders (Button)** integration.

1. Return to SuperOffice CRM: click the **Main menu** (<i class="ph ph-list" aria-hidden="true"></i>) and select **SuperOffice CRM**.
1. Click **New** > **Selection** to [create a selection][5].
1. Select **Find Product**.
1. [Add a criterion][3] with **Code** as the field, **Is not** as the operator, and a single space character as the value.
1. Run the search and confirm that at least one result appears. An empty selection may cause DataBridge to fail when the integration runs.
1. Save as a **dynamic selection** with the name **DB – Template: Quote**.

![Find Product with criteria Code Is not (space) -screenshot][img3]

## 5. Import the order sync integration

### Integration 6: Visma Net Sales Orders (Button)

This integration is triggered manually when a user clicks **Create Order in Visma Net**.

1. In DataBridge, import the corresponding *.ndb* file.
1. Connect to Visma Net.
1. Select the **DB – Template: Quote** selection as the data source.
1. After saving, copy the **Instant Job URL**. You'll need it in [Add the Instant Job URL to the CRMScript](#6-add-the-instant-job-url-to-the-crmscript).

### Integration 7: Visma Net Sales Orders (Hourly)

This integration runs automatically every hour to pull new and updated sales orders from Visma Net into SuperOffice.

1. In DataBridge, import the corresponding *.ndb* file.
1. Connect to Visma Net.
1. After saving, **disable the integration immediately**. You'll enable it in [Verify and finalize][2].

## 6. Add the Instant Job URL to the CRMScript

1. Go to **Settings and maintenance** > **CRMScript**.
1. Open the **Order to Visma Net** script.
1. Set the `instantJobUrl` variable to the URL you copied from **Visma Net Sales Orders (Button)**.
1. Save.
