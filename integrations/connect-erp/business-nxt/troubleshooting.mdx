## Import of an integration {#import}

### DataBridge shows an error when you import an integration

DataBridge shows warnings with a yellow background and errors with a red background while you import an integration. For a warning, read the message and follow its instructions. The warning that not all fields to create a company are mapped is expected for the person sync integrations.

An error usually has one of these causes:

* A user-defined field doesn't have the Prog ID from [Set up company sync][1], [Set up contact sync][2], or [Set up order sync][3].
* The Business NXT fields aren't set up as described.
* DataBridge doesn't know a user-defined field yet, because you created it only a few minutes ago. A new field can take some time to show up in DataBridge.

To fix it, check the field definitions, delete the integration, and import it again. The messages disappear after a few seconds, so take a screenshot when they show.

## Customers and suppliers {#associate}

### Import a customer instead of an associate

Business NXT has an associate entity as a generic base entity for other entities, such as customer and supplier. DataBridge offers the generic entity Associate to import any type.

The downside of the Associate entity is that the fields that are specific to a customer or a supplier aren't available.
