If companies already exist in both SuperOffice and Business NXT before the integration is set up, you can use the initial match process to link them without creating duplicates. The match is a manual process, because someone has to check that the right companies are matched.

Do the initial match before you enable the automated synchronizations in [Verify and finalize][2]. If no companies exist in both systems, skip these steps.

<Note>
Download the initial match DataBridge integrations from the [Downloads][1] section in Requirements (*databridge-integrations-initial-import-business-nxt.zip*) before starting.
</Note>

## Overview

The initial match uses three DataBridge integrations:

| Integration | Purpose |
|---|---|
| Business NXT Initial 1/3 (Business NXT) | Exports a list of all customers from Business NXT |
| Business NXT Initial 2/3 (SuperOffice) | Exports a list of all companies from SuperOffice |
| Business NXT Initial 3/3 (Link) | Imports the matched company pairs |

## 1. Export both lists

1. In DataBridge, run **Business NXT Initial 1/3 (Business NXT)** to generate a list of Business NXT customers.
1. Run **Business NXT Initial 2/3 (SuperOffice)** to generate a list of SuperOffice companies.

DataBridge creates an Excel file for each list.

![DataBridge: Business NXT Initial 1/3 (Business NXT) integration setup -screenshot][img1]

## 2. Match the companies

Compare the two lists and create an import file with at least two columns:

| Column | Description |
|---|---|
| `SuperOffice_Company_Number` | The SuperOffice company number |
| `BusinessNXT_Company_Number` | The corresponding Business NXT customer number |

<Danger>
Review and verify every match before importing. Incorrect links cause data to be written to the wrong company records.
</Danger>

## 3. Import the matches

1. In DataBridge, open **Business NXT Initial 3/3 (Link)**.
1. Use the completed match file as the import source.
1. Run the integration. It links the existing companies, and it doesn't create new companies.
1. In SuperOffice, verify that the **ERP Cust. Number** field is populated on the linked companies.
