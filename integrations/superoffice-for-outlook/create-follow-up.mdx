To create a task or appointment in SuperOffice directly from Outlook, select **Create task** or **Create appointment** in the SuperOffice sidebar. In SuperOffice, this is known as a [follow-up][1].

1. Open the email related to the activity.

1. Check the contact at the top of the sidebar. If it shows **Select contact** or **Click to add new contact**, [match the contact][2] first.

1. In the **SuperOffice** Outlook sidebar, select **Create task** or **Create appointment**.

1. Fill in the required fields:

    * **Contact or Company**: Select the contact or company for this task or appointment.

        <StepContactOrCompanyMatch />

        <StepFindContactOrCompany />

    * **Sale** (Optional): Link the follow-up to an existing sale if relevant.
    * **Project** (Optional): Link the follow-up to an ongoing project if applicable.
    * **Type**: Choose the type of follow-up (such as, Customer complaint, Meeting).
    * **Date**: Set the date for the task or appointment.
    * **Time** (appointments only): Set the time for the appointment.
    * **Visible for**: Choose who can see the appointment or task: **All**, a user group, or only you.

        <NoteVisibility />

    * **Description**: Filled in with the email subject and body text. You can edit the text or add details, such as a case number or other context.

1. Once all fields are completed, click **Save**.

    ![SuperOffice for Outlook, Create follow-up -screenshot][img1]

You can also create a sale or request directly from the email. If it is part of an ongoing issue, you can attach the message to a specific request.
