If SuperOffice finds one matching contact, this field is filled in automatically. If the email address is registered on several contacts, select **Select contact** in the main panel before you open this panel. If no contact is found, select **Click to add new contact** in the main panel and enter the details. Otherwise this field stays empty until you select a contact or company here.
