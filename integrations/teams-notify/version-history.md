## Release 11 (2025-11-19)

Rebranding updates only. No functional changes or bug fixes.

## Release 10 (2025-01-31)

* Removed support for webhooks set up with the SuperOffice for Microsoft Teams connector, which is now deprecated.
* When you create a connection to Microsoft Teams in the portal, consent is now requested only for the initial connection.
* Internal improvements and maintenance.

## Release 9 (2025-01-20)

* Added an announcement in the SuperOffice for Microsoft Teams connector about its deprecation on January 31. Customers had to migrate by then to keep receiving SuperOffice events.
* Added a settings page to the portal for advanced SuperOffice event filtering across multiple Microsoft Teams channels.
* Added automatic migration for users when the new settings are configured.
* Renamed *contact* to *company* in the channels and events configuration.

## Release 8 (2023-05-23)

* Internal improvements and maintenance.

## Release 5 (2022-05-20)

* Added insights for an extra layer of security.

## Release 4 (2022-03-14)

* Improved the reset settings page.
* Technical migrations for the internal framework.
* Fixed an issue where event information was shown incorrectly when multi-language was configured in SuperOffice.

## Release 3 (2022-02-14)

* Added the ability to reset settings.
* Added advanced settings to filter created and edited sales on sale probability and amount.

## Release 2 (2022-01-07)

* Added notifications for created service tickets.
* Added the ability to set up different events per Microsoft Teams channel.
* Small changes to the privacy policy.
* Proactive validation of active webhooks.
* Users are redirected to the settings page after first registration.
* More detailed logging and insights into customer settings.
* Fixed an issue that affected the configuration of customer settings.

## Release 0

* Initial release.
