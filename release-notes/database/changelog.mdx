<Update label="12.5" description="10.13.2026">

### SuperOffice

**Step 155**

Create table authentication_session (per-user authenticated session with encrypted OIDC tokens, last seen and ns_secret expiry) and add a foreign key from login to it

* Add table authentication\_session
* Modify table login
authentication\_session\_id

**Step 156**

Repair person.activeInterests and contact.activeInterests where the denormalized counter disagrees with the number of interest link rows whose list item is not deleted, which is what draws the interest indicator in lists. Corrects the descriptions of those fields, which claimed the counter equals the raw number of link rows

Bug 118450 (merging moved the interest link rows at row level without recounting) and Bug 21531 (deleting an
interest list item left the counters of everyone linked to it untouched) are fixed in code; this repairs the
rows that have already drifted.

* Modify table person
activeInterests
* Modify table contact
activeInterests
* Modify table personinterest

**Step 157**

Adding prospecting/enrichment fields to contact and person

* Modify table contact
numEmployees, yearFounded, revenueYear, revenueBasecurrency, sharecapitalBasecurrency, sourcedFrom, linkedinUrl, contextText\_id
* Modify table person
sourcedFrom, linkedinUrl, contextText\_id

**Step 158**

Prime LocaleText resourceIds 26/28/29 (PushNotificationTextResources.TicketRequestIdentity/TicketTakenOverTitle/TicketTakenOverTitleGeneric) for the TicketCustomMessage/TicketTakenOver mobile push notifications added in PR 48936. English (1033) only - resourceId is not scoped per typeid in this table, so a full re-sync of every existing typeid=41 row (not just an incremental Truncate_field on the new resourceIds) is required to avoid deleting unrelated rows that reuse the same resourceId under a different typeid (e.g. 26/28 already exist under typeid 7/11/12). The other 15 languages need translation before the next full re-sync of this typeid.

**Step 159**

Add functional right 'Delete externally owned follow-ups'

Adds the 'delete-external-follow-ups' functional right with its name and tooltip; the role admin only lists
rights that have both. It is not linked to any role: admin-all implies it in AppointmentSentry, and other
roles get it by assignment in the role admin.
