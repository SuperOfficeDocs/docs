**Removing the More tab? Check your mandatory fields first.**

Mandatory user-defined fields are often placed on the **More** tab. If you remove
that tab, any mandatory field living there no longer has anywhere to appear —
which means users won't be able to save new records, and the disabled **Save**
button won't make the reason obvious.

Before removing the **More** tab, make sure every mandatory field is either moved
to a tab you're keeping, or is no longer set as mandatory.
</Danger>
